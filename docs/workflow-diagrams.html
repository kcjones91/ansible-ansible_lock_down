📚 Quick Reference Commands

🏗️ Deploy Infrastructure

terraform init terraform apply

📦 Setup Ansible Roles

.\setup.cmd

🔍 Dry Run

.\ansible.cmd playbook cis-hardening-all.yml --check --diff

🚀 Apply Hardening

.\ansible.cmd playbook cis-hardening-all.yml

🐧 Linux Only

.\ansible.cmd playbook cis-hardening-linux.yml

🪟 Windows Only

.\ansible.cmd playbook cis-hardening-windows.yml
